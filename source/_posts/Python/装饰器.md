## 1. [Python装饰器](https://gairuo.com/p/python-decorator)

**核心目标：理解装饰器（Decorator）的本质**

想象一下，你有一个功能完善的函数（比如 `foo(x)`），现在你想给它添加一些**通用的、非核心业务**的功能，比如：

* 记录这个函数什么时候开始执行、什么时候结束。
* 计算这个函数执行花了多长时间。
* 检查用户是否有权限执行这个函数。
* 把函数的结果缓存起来，下次同样的输入直接返回结果，不用再计算。

**最笨的方法是什么？** 直接修改 `foo(x)` 函数内部的代码，在里面加上记录开始、记录结束的语句。

**缺点是什么？**

1. **违反“开闭原则”**：开闭原则是说对扩展开放，对修改关闭。直接修改原函数意味着你修改了它的实现，而不是扩展它。
2. **重复代码**：如果你有 100 个函数都需要记录执行时间，你就要把这套记录时间的代码复制粘贴 100 遍！维护起来会是一场噩梦。
3. **污染核心逻辑**：记录时间、检查权限这些代码和 `foo(x)` 本身要计算 `x` 的功能混合在一起，代码可读性变差。

**装饰器就是为了解决这些问题而生的！**

**装饰器的核心思想：**

* **不修改原函数：** 原有函数 `foo(x)` 的代码一行都不动。
* **“包裹”原函数：** 创建一个新的函数（或可调用对象），这个新函数内部会调用原函数，并在调用**之前**和/或**之后**添加你想要的额外功能。
* **语法糖 `@decorator_name`：** 这是 Python 提供的一种简洁语法，让你能非常方便地把装饰器应用到一个函数（或类）上。

**从零理解装饰器**

**步骤 1：理解基础 - 函数也是对象（高阶函数）**

在 Python 中，**函数本身也是对象**，可以像整数、字符串一样被赋值、传递给其他函数、作为其他函数的返回值。这是理解装饰器的基石。

```
def say_hello(name):
    return f"Hello, {name}!"

# 1. 赋值函数对象
greet = say_hello
print(greet("Alice"))  # 输出: Hello, Alice!

# 2. 把函数作为参数传递
def call_twice(func, arg):
    print(func(arg))
    print(func(arg))

call_twice(say_hello, "Bob")
# 输出:
# Hello, Bob!
# Hello, Bob!

# 3. 函数作为返回值
def create_greeter(greeting):
    def greeter(name):
        return f"{greeting}, {name}!"
    return greeter

morning_greet = create_greeter("Good morning")
print(morning_greet("Charlie"))  # 输出: Good morning, Charlie!
```

**关键点：** `create_greeter` 返回了内部定义的 `greeter` 函数。`morning_greet` 实际上指向了 `greeter` 函数，并且它“记住”了外层函数传入的 `greeting="Good morning"` 这个值（这就是 **闭包**）。

**步骤 2：定义你的第一个装饰器（日志记录）**

博客里的例子很好，我们来详细拆解：

```
# 1. 定义装饰器函数 log
def log(func):  # func 参数就是要被装饰的那个函数（比如 foo）
    # 2. 定义内部函数 decorator, 它负责“包裹”原函数
    # *args, **kwargs 表示它能接受任意数量和类型的位置参数和关键字参数，确保能原样传递给 func
    def decorator(*args, **kwargs):
        # 3. 添加额外功能：在调用原函数前打印日志
        print(f"开始执行: {func.__name__}")
        # 4. 调用原函数 func，并获取它的返回值
        result = func(*args, **kwargs)  # 关键：执行被装饰的函数
        # 5. 添加额外功能：在调用原函数后打印日志
        print("执行结束")
        # 6. 返回原函数的执行结果
        return result
    # 7. 将包裹好的 decorator 函数返回
    return decorator
```

**分析：**

* `log` 是一个装饰器**工厂函数**，它接收一个函数 `func` 作为参数。
* 在 `log` 内部，定义了 `decorator` 函数。**`decorator` 才是真正“取代”原函数的新函数。**
* `decorator` 做三件事：
  1. 执行前操作（打印开始日志）。
  2. 调用原函数 `func(*args, **kwargs)`（用 `*args, **kwargs` 保证能处理原函数的所有参数），并捕获结果。
  3. 执行后操作（打印结束日志），并返回原函数的结果。
* `log(func)` 的返回值是 `decorator` 这个内部函数。

**步骤 3：应用装饰器（使用 `@` 语法糖）**

现在，我们想把这个日志功能加到原来的 `foo` 函数上。

**旧 `foo`：**

```
def foo(x):
    print(f'foo out: {x}')
```

**应用装饰器：**

```
@log  # 这行是关键！等价于执行：foo = log(foo)
def foo(x):
    print(f'foo out: {x}')
```

**发生了什么魔法？**

* `@log` 放在 `def foo(x): ...` 上面，是 Python 提供的一个**语法糖**。
* 它的作用等价于在执行完 `def foo(x): ...` 之后，**立刻**执行：`foo = log(foo)`
  * 先定义 `foo` 函数（原版）。
  * 然后将 `log` 装饰器作用于 `foo`：`log(foo)` 会执行，它返回的是 `decorator` 函数。
  * 最后，将变量 `foo` **重新绑定** 到 `log(foo)` 返回的 `decorator` 函数上。
* **结论：** 现在当你调用 `foo(...)` 时，你实际上调用的是 `decorator(...)` 函数。`decorator` 函数内部会先打印日志，然后调用**最初的 `foo` 函数**，再打印日志，最后返回 `foo` 的结果。

**步骤 4：调用被装饰的函数**

```
foo('Hello world!')
```

**执行流程：**

1. 调用 `foo('Hello world!')`，此时 `foo` 已经指向 `log(foo)` 返回的 `decorator`。
2. 进入 `decorator('Hello world!')`：
   1. 执行 `print(f'开始执行: {func.__name__}')` -> 输出 `开始执行: foo` (这里的 `func` 是最初的 `foo` 函数对象)。
   2. 执行 `result = func('Hello world!')` -> 调用**最初的 `foo('Hello world!')`** -> 输出 `foo out: Hello world!`。
   3. 执行 `print('执行结束')` -> 输出 `执行结束`。
   4. 返回 `result` (在这个例子中，`foo` 没有返回值，所以 `result` 是 `None`)。

**输出结果：**

```
开始执行: foo
foo out: Hello world!
执行结束
```

**恭喜！** 你成功地在不修改 `foo` 函数内部代码的情况下，给它添加了日志功能！

**步骤 5：理解类装饰器**

博客中提到了类装饰器。它的核心思想是把装饰器定义成一个**类**，而不是一个函数。这个类需要实现 `__call__` 方法，使它本身成为可调用的（Callable），行为类似于上面的 `decorator` 函数。

**博客示例解析：**

```
class InstanceCounter:  # 1. 定义类装饰器
    count = 0  # 2. 类变量，记录所有InstanceCounter装饰的类的实例总数 (这个例子中其实没用上，有点小瑕疵)

    def __init__(self, cls):  # 3. __init__ 接收被装饰的类 (cls)
        self.cls = cls      # 4. 保存被装饰的类
        self.count = 0      # 5. 实例变量，记录这个特定类被实例化的次数

    def __call__(self, *args, **kwargs):  # 6. __call__ 使InstanceCounter的实例可调用
        self.count += 1    # 7. 每次调用（即创建实例）时，计数器加1
        print(f"类 {self.cls.__name__} 被初始化 {self.count} 次.")  # 8. 打印日志
        return self.cls(*args, **kwargs)  # 9. 创建并返回被装饰类的实例

# 10. 应用类装饰器 (语法糖和函数装饰器一样)
@InstanceCounter  # 等价于 MyClass = InstanceCounter(MyClass)
class MyClass:
    def __init__(self, x):
        self.x = x

# 11. 创建实例
instance1 = MyClass(10)  # 触发 __call__
instance2 = MyClass(20)  # 触发 __call__
instance3 = MyClass(30)  # 触发 __call__
```

**执行流程解析：**

1. **`@InstanceCounter`：** 当 Python 看到这行时，它会执行 `MyClass = InstanceCounter(MyClass)`。
   * **`InstanceCounter(MyClass)`：** 调用 `InstanceCounter` 类的构造函数 `__init__(self, cls)`。
     * `self`：新创建的 `InstanceCounter` 实例。
     * `cls`：传入的就是原始的 `MyClass` 类对象。
     * 将 `cls` 保存到 `self.cls`。
     * 初始化 `self.count = 0` (用于计数)。
   * 此时，**变量 `MyClass` 不再指向原始的类定义，而是指向了这个 `InstanceCounter` 的实例对象！** (关键点)
2. **`instance1 = MyClass(10)`：** 现在 `MyClass` 是 `InstanceCounter` 的一个实例，并且这个实例定义了 `__call__` 方法。所以 `MyClass(10)` 等价于调用 `InstanceCounter 实例对象(10)`，这会触发 `__call__(self, 10)` 方法。
   * `self.count += 1`：计数器加1 (第一次变成1)。
   * `print(...)`：打印 "类MyClass 被初始化 1 次."。
   * `return self.cls(10)`：调用**原始的 `MyClass` 类**，传入参数 `10`，创建一个 `MyClass` 的实例并返回。这个返回的实例被赋值给 `instance1`。
3. 后续 `instance2 = MyClass(20)` 和 `instance3 = MyClass(30)` 重复步骤2，计数器依次增加，打印日志，并创建原始 `MyClass` 的实例。

**类装饰器 vs 函数装饰器：**

* **相同点：** 都是不修改原对象（函数/类），通过包裹（wrap）的方式添加功能。都使用 `@` 语法糖。
* **不同点：**
  * **函数装饰器：** 接收一个函数，返回一个新函数（通常是内部定义的闭包函数）。
  * **类装饰器：** 接收一个类，返回一个新对象（通常是它自己的实例，该实例必须可调用 - 实现 `__call__`）。
* **适用场景：** 类装饰器特别适合需要**维护状态**（如博客中的计数器 `self.count`）的装饰逻辑，因为类的实例可以自然地保存状态（实例变量）。函数装饰器如果要用闭包保存状态也可以，但有时用类结构更清晰。

**步骤 6：装饰器的强大应用场景 (重点理解为什么用)**

博客里列了很多，我们来理解几个最常见的：

1. **日志记录 (Logging)：** 我们第一个例子就是。记录函数调用、参数、返回值、执行时间等。对调试和监控至关重要。
2. **性能测试/计时 (Timing/Profiling)：**
   ```
   import time
   def timer(func):
       def wrapper(*args, **kwargs):
           start_time = time.perf_counter()
           result = func(*args, **kwargs)
           end_time = time.perf_counter()
           elapsed = end_time - start_time
           print(f"{func.__name__} 执行耗时: {elapsed:.6f} 秒")
           return result
       return wrapper

   @timer
   def slow_function(n):
       time.sleep(n)
       return "Done"

   slow_function(2)  # 输出: slow_function 执行耗时: 2.000XXX 秒
   ```
3. **缓存 (Memoization)：** 存储函数计算结果，避免重复计算。
   ```
   from functools import lru_cache  # Python标准库提供了一个现成的缓存装饰器

   @lru_cache(maxsize=128)  # 缓存最近128次调用
   def fibonacci(n):
       if n < 2:
           return n
       return fibonacci(n-1) + fibonacci(n-2)

   # 第一次计算fibonacci(30)会比较慢
   # 再次计算fibonacci(30)会瞬间返回结果，因为结果在缓存里
   ```
4. **权限校验/用户认证 (Authentication/Authorization)：** Web开发中常用。
   ```
   def login_required(func):
       def wrapper(request, *args, **kwargs):
           if not request.user.is_authenticated:
               return redirect('/login/')
           return func(request, *args, **kwargs)
       return wrapper

   @login_required
   def secret_view(request):
       return render(request, 'secret.html')  # 只有登录用户才能访问
   ```
5. **事务处理 (Transaction Management)：** 数据库操作时，确保一组操作要么全部成功，要么全部失败回滚。
   ```
   def transactional(func):
       def wrapper(*args, **kwargs):
           connection = get_database_connection()
           try:
               connection.begin_transaction()
               result = func(*args, **kwargs)  # 执行包含数据库操作的函数
               connection.commit()
               return result
           except Exception as e:
               connection.rollback()
               raise e
       return wrapper
   ```
6. **数据验证/格式化 (Validation/Sanitization)：** 验证函数输入参数是否合法，或对输出结果进行格式化。
   ```
   def validate_integer(func):
       def wrapper(x):
           if not isinstance(x, int):
               raise ValueError("参数必须是整数!")
           return func(x)
       return wrapper

   @validate_integer
   def square(x):
       return x * x

   square(5)  # 25
   square('a')  # 抛出 ValueError: 参数必须是整数!
   ```

**步骤 7：认识内置装饰器**

Python 自身提供了一些非常有用的内置装饰器：

1. **`@property`：** 把一个方法变成“属性”来访问。用于封装实例变量，提供计算属性或添加访问控制逻辑。
   ```
   class Circle:
       def __init__(self, radius):
           self._radius = radius  # 约定：下划线开头表示“私有”（实际还是公开）

       @property
       def radius(self):  # 现在可以像属性一样访问：circle.radius
           return self._radius

       @radius.setter
       def radius(self, value):  # 设置属性：circle.radius = 5
           if value <= 0:
               raise ValueError("半径必须为正数")
           self._radius = value

       @property
       def area(self):  # 计算属性：circle.area
           return 3.14 * self._radius ** 2

   c = Circle(5)
   print(c.radius)  # 5 (像访问属性一样调用radius() getter方法)
   print(c.area)    # 78.5 (调用area()方法)
   c.radius = 10    # 调用radius() setter方法
   ```
2. **`@staticmethod`：** 声明一个静态方法。**不**需要类的实例（`self`）或类本身（`cls`）作为第一个参数。它跟普通函数一样，只是放在类里面方便组织代码。
   ```
   class MathUtils:
       @staticmethod
       def add(x, y):
           return x + y

   # 不需要创建MathUtils实例
   result = MathUtils.add(2, 3)  # 5
   ```
3. **`@classmethod`：** 声明一个类方法。它的第一个参数是**类本身**（通常命名为 `cls`），而不是实例（`self`）。常用于创建工厂方法（构造函数的替代方案）或操作类级别的数据。
   ```
   class Pizza:
       def __init__(self, ingredients):
           self.ingredients = ingredients

       @classmethod
       def margherita(cls):  # cls 指 Pizza 类
           return cls(['mozzarella', 'tomatoes'])  # 相当于调用 Pizza(...)

       @classmethod
       def prosciutto(cls):
           return cls(['mozzarella', 'tomatoes', 'ham'])

   # 使用类方法创建特定风味的Pizza实例
   p1 = Pizza.margherita()  # 创建了一个Pizza(['mozzarella', 'tomatoes'])
   p2 = Pizza.prosciutto()
   ```

**总结与要点回顾（老师叮嘱）：**

1. **核心目标：** 装饰器让你能在**不修改原函数或原类代码**的前提下，**动态地添加额外功能（横切关注点）**。它符合 **AOP（面向切面编程）** 的思想。
2. **本质：** 装饰器是一个**高阶函数**（接收函数作为参数并返回函数的函数）或一个**实现了 `__call__` 的类**（类装饰器）。
3. **关键机制：**
   * **闭包 (Closure)：** 内部函数（`decorator`/`wrapper`）能记住并访问外部函数（`log`）的作用域（如 `func` 参数）。
   * **函数对象特性：** 函数可以作为参数传递和作为返回值。
   * **`@` 语法糖：** `@decorator` 等价于 `func = decorator(func)`。
4. **优势：**
   * **代码复用 (DRY)：** 避免重复代码。
   * **关注点分离 (Separation of Concerns)：** 核心业务逻辑与日志、计时、验证等辅助逻辑分离。
   * **可维护性：** 添加/修改功能只需改装饰器，不用改各个函数。
   * **灵活性：** 可以动态添加或移除功能。
5. **重要提醒：**
   * **元信息丢失：** 装饰后函数的名字（`__name__`）、文档字符串（`__doc__`）等会变成装饰器内部函数的信息。使用 `functools.wraps` 装饰器可以解决：
     ```
     from functools import wraps
     def log(func):
         @wraps(func)  # 保留func的元信息
         def decorator(*args, **kwargs):
             ...
         return decorator
     ```
   * **多个装饰器：** 可以叠加使用（`@deco1 @deco2 def foo(): ...`），执行顺序是**由内向外**（deco2 包裹 deco1，deco1 包裹 foo）。
   * **带参数的装饰器：** 如果需要装饰器本身也能接收参数（如 `@cache(expire=3600)`），需要再多一层嵌套函数（闭包套闭包）。
