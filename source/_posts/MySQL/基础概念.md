数据库？数据库管理系统？SQL？

## 基础概念

- 数据库：数据存储的仓库；
- 数据库管理系统：操纵和管理数据库的大型软件；
- SQL：操作关系型数据库的编程语言，是一套标准；

用户通过SQL编程语言操作数据库管理系统，从而管理数据库；

### MySQL启动与停止

方式一

-  `services.msc`

方式二：

- net start mysql
- net stop mysql

mysql默认是开机自启。

### 客户端连接

```bash
$ mysql [-h 127.0.0.1] [-P 3306] -u root -p
```

- -h：指定IP
- -P：指定端口
- -u：指定用户
- -p：指定密码

### 数据模型

关系型数据库：

- 建立在关系模型基础上，由多张相互连接的二维表格组成的数据库；

## 语法

SQL分类：

- DDL：数据定义语言，用来定义数据库对象；
- DML：数据操作语言，用来对数据库表中的数据进行增删改；
- DQL：数据查询语言，用来查询数据库中表的记录；
- DCL：数据控制语言，用来创建数据库用户，控制数据库的访问权限；

### DDL

数据库操作：

- 查询
  - show databases;
  - select database();
- 创建
  - create database [name];
- 删除
  - drop database [name];
- 使用
  - use [name];

表操作：

- 查询
  - show tables;
  - desc [table name];
  - show create table [table name];
- 创建
  - `create table [table name](字段 字段类型，字段 字段类型)；`
- 修改
  - alter table [table name] add/modify/change/drop/rename to ...;
- 删除
  - drop table [table name];
